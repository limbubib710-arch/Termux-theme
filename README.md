</p>🚀 About

Universal Termux Bash Theme Customizer is an open-source project designed to transform the default Termux terminal into a customized and stylish environment.

It provides theme customization, colorful Bash prompts, terminal banners, and convenient shell configuration options.

✨ Features

- 🎨 Multiple terminal themes
- 🔥 Custom Bash PS1 prompt
- 💻 Hacker-style terminal interface
- 🌈 Colorful terminal appearance
- 🎭 Custom ASCII banners
- ⚡ Bash aliases and functions
- 📂 Organized configuration directory
- 🔄 Theme switching support
- 💾 Configuration backup and restore
- 🗑️ Uninstall and reset support
- 📱 Android Termux compatible
- 🔓 No root required
- 🌍 Open-source project

📦 Requirements

- Android device
- Termux
- Git
- Bash

📥 Installation

Update Termux packages:

pkg update -y && pkg upgrade -y

Install Git:

pkg install git -y

Clone this repository:

git clone httpsgit clone https://github.com/limbubib710-arch/


Open project directory:

cd YOUR_PROJECT_FOLDER

Run installer:

bash install.sh

🎨 Usage

After installation, launch the theme manager:

termux-theme

Available commands depend on the installed version:

theme list
theme preview
theme install
theme reset
theme uninstall
theme help
